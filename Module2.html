08 · Garbage Collection

What Is Garbage Collection?

Garbage collection is the automatic process by which Java reclaims memory used by objects that are no longer reachable.

08 · Garbage Collection

Garbage Collection — In Simple Words

•
An object is eligible when no live reference can reach it.
•
Setting a reference to null may make an object unreachable.
•
The garbage collector decides when to reclaim eligible memory.
•
Program code should not rely on a specific garbage-collection time.
08 · Garbage Collection

Garbage Collection — Important Points

•
An object is eligible when no live reference can reach it.
•
Setting a reference to null may make an object unreachable.
•
The garbage collector decides when to reclaim eligible memory.
•
Program code should not rely on a specific garbage-collection time.

        ↓
JVM may reclaim memory
08 · Garbage Collection

09 · Method Overloading

Method Overloading — In Simple Words

•
The method name stays the same.
•
The number, types or order of parameters must differ.
•
Changing only the return type is not enough.
•
The compiler selects the applicable overloaded method at compile time.
09 · Method Overloading

Method Overloading — Important Points

•
The method name stays the same.
•
The number, types or order of parameters must differ.
•
Changing only the return type is not enough.
•

11 · Recursion

What Is Recursion?

Recursion is a technique in which a method calls itself to solve a problem by working on smaller instances of it.

11 · Recursion

Recursion — In Simple Words

•
A recursive method needs a base case.
•
The recursive case moves toward the base case.
•
Each call gets its own stack frame.
•
Missing or incorrect stopping conditions can cause StackOverflowError.
11 · Recursion

Recursion — Important Points

•
A recursive method needs a base case.
•
The recursive case moves toward the base case.
•
Each call gets its own stack frame.
•
Missing or incorrect stopping conditions can cause StackOverflowError.
11 · Recursion

General Syntax

returnType methodName(input) {
    if (baseCase) return result;
    return methodName(smallerInput);
}
11 · Recursion

Syntax — Understand the Parts

•
A recursive method calls itself.
•
Each call should move toward a smaller or simpler problem.
•
A base case stops the recursive calls.

Access control determines where a class or its members can be accessed in a Java program.

12 · Access Control

Access Control — In Simple Words

•
public allows broad access, subject to class accessibility.
•
private restricts access to the declaring class.
•
protected allows access in the same package and, with additional rules, in subclasses.
•
No modifier gives package access.
12 · Access Control

Access Control — Important Points

•
public allows broad access, subject to class accessibility.
•
private restricts access to the declaring class.
•
protected allows access in the same package and, with additional rules, in subclasses.
•
No modifier gives package access.
