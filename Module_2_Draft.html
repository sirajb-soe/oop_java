02 · Class Fundamentals
CLASS FUNDAMENTALS
02 · Class Fundamentals

Definition

A class is a blueprint that defines the data and behavior of objects. It groups fields, constructors, and methods into one logical unit.

02 · Class Fundamentals

In Simple Words

• Class = blueprint: it describes what an object has and what it can do.
• Fields store the state of an object.
• Methods define the behavior of an object.
• A class definition does not create an object by itself.
• Objects are created from a class using new.

    dataType fieldName;

}
02 · Class Fundamentals

02 · Declaring Objects
DECLARING OBJECTS
02 · Declaring Objects

Definition

Declaring an object means creating a reference variable of a class type and, when required, using new to create the actual object in memory.

02 · Declaring Objects

In Simple Words

• First, the class defines the object type.
• A reference variable can be declared without immediately creating an object.
• new creates an object and returns its reference.
• The dot operator . accesses fields and methods through the reference.
• An object can be created and assigned in a single statement.

02 · Object Reference Variables
OBJECT REFERENCE VARIABLES
02 · Object Reference Variables

Definition

An object reference variable stores a reference to an object rather than storing the complete object itself. Multiple references can refer to the same object.

02 · Object Reference Variables

In Simple Words

• A reference variable has a class type, such as Student s.
• It can refer to an object created with new.
• Two references may point to the same object.
• Assigning one reference to another copies the reference, not the object.
• null means the reference currently refers to no object.

ClassName a = null;Reference points to no object.

02 · Methods
METHODS
02 · Methods

Definition

A method is a named block of code inside a class that performs a specific operation. Methods improve reuse, structure, and readability.

02 · Methods

In Simple Words

• A method may take parameters as input.
• A method may return a value or use void when it returns nothing.
• Methods are invoked using an object reference for instance methods.
• Method parameters receive values from the caller.
• A method can be called multiple times with different arguments.

02 · Constructors
CONSTRUCTORS
02 · Constructors

Definition

A constructor is a special member of a class used to initialize objects. It has the same name as the class and has no return type.

02 · Constructors

In Simple Words

• Constructors run automatically when an object is created with new.
• A class can have more than one constructor.
• A no-argument constructor initializes an object without parameters.
• A parameterized constructor receives initial values.
• A copy constructor is a programmer-defined constructor that initializes one object from another.

02 · this Keyword
THIS KEYWORD
02 · this Keyword

Definition

The this keyword refers to the current object. It is commonly used to distinguish instance fields from parameters and to invoke another constructor or method of the current object.

02 · this Keyword

In Simple Words

• this.field explicitly refers to the current object's field.
• this() calls another constructor in the same class.
• this.method() explicitly calls the current object's method.
• It removes ambiguity when parameter names match field names.
• In a constructor, this refers to the object currently being initialized.
02 · this Keyword

return this;Returns the current object reference.

02 · Garbage Collection
GARBAGE COLLECTION
02 · Garbage Collection

Definition

Garbage collection is Java's automatic memory-management process that identifies objects that are no longer reachable and can reclaim their memory.

02 · Garbage Collection

In Simple Words

• Java automatically manages object memory; programmers normally do not call free().
• An object becomes eligible for collection when it is no longer reachable from live references.
• System.gc() requests garbage collection; it does not guarantee immediate collection.
• Garbage collection helps reduce manual memory-management errors.
• Object eligibility and actual collection are different events.
02 · Garbage Collection

02 · Garbage Collection

System.gc();Requests that the JVM consider garbage collection.
Runtime.getRuntime().gc();Another way to request GC.
no live reference → objectAn unreachable object is eligible for collection.

02 · Method Overloading
METHOD OVERLOADING
02 · Method Overloading

Definition

Method overloading occurs when a class has multiple methods with the same name but different parameter lists. It is a form of compile-time polymorphism.

02 · Method Overloading

In Simple Words

• Overloaded methods use the same method name.
• The parameter list must differ by number, type, or order of parameters.
• Changing only the return type does not create a valid overload.
• Java selects the applicable method at compile time.
• Overloading improves readability when operations are conceptually related.
02 · Method Overloading

02 · Passing Objects to Methods
PASSING OBJECTS TO METHODS
02 · Passing Objects to Methods

Definition

Java allows an object reference to be passed as a method argument. The method receives a copy of the reference value, so it can access or modify the referenced object's state.

02 · Passing Objects to Methods

In Simple Words

• An object can be supplied as a method argument.
• The parameter type is the class name.
• Changes to the object's fields can be visible to the caller.
• Java is pass-by-value; for objects, the value passed is a copy of the reference.
• Reassigning the parameter reference does not reassign the caller's reference.

02 · Recursion
RECURSION
02 · Recursion

Definition

Recursion is a technique in which a method calls itself to solve a problem by reducing it to smaller instances of the same problem.

02 · Recursion

In Simple Words

• Every recursive solution needs a base case.
• The recursive case makes progress toward the base case.
• Each call creates a new stack frame.
• Recursion is useful for factorials, tree traversal, divide-and-conquer, and similar problems.
• Without a terminating base case, recursion can cause StackOverflowError.
02 · Recursion

General Syntax

GENERAL SYNTAX
returnType methodName(parameters) {

    return methodName(smallerInput);

}
02 · Recursion

Syntax Explanation

SyntaxWhat it means
returnType methodName(parameters) { ... }Defines the recursive method.
if (condition) return value;Stops recursion.
return methodName(smallerInput);Solves a smaller instance.
input becomes smallerMoves toward termination.
02 · Recursion
Example 1

See It in Action

public class Main {

    static int factorial(int n) {

        if (n <= 1) return 1;

        return n * factorial(n - 1);

    }

    public static void main(String[] args) {

        System.out.println(factorial(5));

    }

}
