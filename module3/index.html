01 · Module 3 concept
INHERITANCE
Inheritance

Definition

Inheritance allows a subclass to reuse accessible fields and methods from a superclass.

Inheritance

In simple words

A child class gets common behaviour from a parent class and can add its own features.

AnimalSuperclasseat()
↓ extends
DogSubclassbark() + eat()
Inheritance

General syntax

class Dog extends Animal {
    // add Dog-specific behaviour
}
Inheritance

Syntax breakdown

Code elementMeaning
class DogDeclares the subclass
extends AnimalInherits from Animal
Class bodyAdds or specializes behaviour
Inheritance

Example program 1

class Main {
    static class Animal {
        void eat() { System.out.println("Eating"); }
    }
    static class Dog extends Animal {
        void bark() { System.out.println("Barking"); }
    }
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat();
        d.bark();
    }
}

Definition

Multilevel Inheritance

In simple words

AnimalLevel 1 · base class
↓ extends
MammalLevel 2 · inherits Animal
↓ extends
DogLevel 3 · inherits Mammal
Multilevel Inheritance

General syntax

class B extends A { }
class C extends B { }
Multilevel Inheritance

Syntax breakdown

Code elementMeaning

B extends ASecond level
C extends BThird level
ResultC can use accessible members inherited through the chain

METHOD OVERLOADING
Method Overloading

Definition

Method overloading means defining methods with the same name but different parameter lists.

Method Overloading

In simple words

Use one meaningful method name for related operations that accept different inputs.

Use one meaningful method name for related operations that accept different inputs.
Method Overloading

General syntax

int add(int a, int b) { ... }
int add(int a, int b, int c) { ... }
Method Overloading

Syntax breakdown

Code elementMeaning
Same method nameShared operation
Different parametersNumber, type, or order differs
Return type aloneCannot distinguish overloads
ResolutionCompiler chooses a matching overload
Method Overloading

Example program 1

class Main {
    static class Calculator {
        int add(int a, int b) { return a + b; }
        int add(int a, int b, int c) { return a + b + c; }

    public static void main(String[] args) {
        Calculator c = new Calculator();
        System.out.println(c.add(2, 3));
        System.out.println(c.add(2, 3, 4));
    }
}
