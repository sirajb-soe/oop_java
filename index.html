Java in One Definition

Java is a high-level, class-based, object-oriented programming language designed to be portable, robust, and widely applicable.

What Are Data Types?

A data type tells Java what kind of value a variable can store and how that value is represented.

06 · Data Types

Data Types — Key Points

•They define the kind of value a variable can store.
•They help Java use memory correctly for the stored value.
•They determine valid operations and how Java interprets the value.
Two broad groups are used in Java: Primitive types and Reference types.
06 · Data Types

Two Main Categories

Primitive

Built-in basic data types such as int, double, char and boolean.

Reference

Types that refer to objects, such as String, arrays and user-defined classes.

06A · Type Inference

What Is Type Inference?

01

Meaning

Java can infer a local variable's type from its initializer.

02

Keyword

Use the var keyword.

03

Important

The type is still fixed after compilation; var is not dynamic typing.

06A · Type Inference

var — Key Points

•Local variables only: commonly used inside methods, blocks and loops.
•Initializer required: Java needs a value from which to infer the type.
•Cannot mean 'any type': after inference, the variable has a specific compile-time type.
Think: var removes repeated type spelling; it does not remove Java's static typing.
06A · Type Inference

General Syntax

General Syntax
var variableName = value;
Example: var marks = 85; → Java infers int.
06A · Type Inference

How var Is Inferred

01

Source

var marks = 85;

02

Compiler

Sees the initializer 85.

03

Inferred Type

marks becomes an int variable.

06A · Type Inference

See It in Action · Example

General Syntax
var name = "Java";
var marks = 85;
var passed = true;
Java infers String, int and boolean.
06A · Type Inference

When var Cannot Be Used

•No initializer: var x; is invalid.
•Fields: var cannot be used for instance or class fields.
•Method parameters / return types: use explicit types.

06B · Type Casting

What Is Type Casting?

01

Meaning

Converting a value from one data type to another compatible type.

02

Two Directions

Widening conversion and narrowing conversion.

03

Why?

Useful when different numeric types must work together.

06B · Type Casting

Type Casting — Key Points

•Widening: smaller compatible numeric type → larger type; usually automatic.
•Narrowing: larger numeric type → smaller type; requires explicit casting.
•Risk: narrowing can lose fractional data or range.
06B · Type Casting

General Syntax

General Syntax
targetType variable = (targetType) value;
Example: int x = (int) 12.8; → x becomes 12.
06B · Type Casting

Widening Conversion

General Syntax
int marks = 85;
double score = marks;
The int value is safely promoted to double. This is an implicit conversion.
06B · Type Casting

Narrowing Conversion

General Syntax
double price = 99.75;
int amount = (int) price;
The cast is explicit. The fractional part is discarded, so amount becomes 99.
06B · Type Casting

Casting — Quick Comparison

01

Widening

Automatic in compatible cases • int → long → float → double

02

Narrowing

Explicit cast required • double → int

03

Remember

Check for possible loss of information.
