01 · Introduction to Java
INTRODUCTION TO JAVA
01 · Introduction to Java

Definition

Java is a high-level, class-based, object-oriented programming language designed to be portable, robust, and widely applicable.

01 · Introduction to Java

In Simple Words

• Java lets us write programs using classes and objects.
• Java source code is compiled into bytecode.
• Bytecode can run on a Java Virtual Machine (JVM).
• This supports the idea: Write Once, Run Anywhere.
01 · Introduction to Java

Why Learn Java?

Object-Oriented

Programs are organized around classes and objects.

Platform Independent

Java bytecode runs on systems with a compatible JVM.

Robust

Strong type checking and runtime features support reliable programs.

Widely Used

Java is used in enterprise software, backend systems, Android history, tools, and education.

01 · Introduction to Java

Key Idea

Source Code → Compiler → Bytecode → JVM → Execution

Java's Beginning

The history of Java explains how the language evolved from an early project into a widely used programming platform.

02 · History of Java

The Early Beginning

1991

The Green Project began at Sun Microsystems.

James Gosling

A key figure in the development of Java.

Original Name

The language was initially called Oak.

Java

The name Java was later adopted.

Important Milestones

1995

Java was publicly introduced.

1996

The first major Java Development Kit (JDK 1.0) was released.

2006

Sun began releasing much of Java as open source.

2010

Oracle acquired Sun Microsystems.

02 · History of Java

Why Java Became Popular

Java combined object-oriented programming, automatic memory management, portability through the JVM, and a growing standard library and ecosystem.

03 · JDK

What Is the JDK?

JDK stands for Java Development Kit. It provides the tools required to develop, compile, test, and run Java programs.

03 · JDK

In Simple Words

• JDK is mainly for developers.
• It includes the Java compiler and other development tools.
• A JDK installation provides the components needed to build Java applications.
03 · JDK

Important JDK Components

javac

Java compiler: converts source code into bytecode.

java

Launches a Java application.

javadoc

Generates API documentation from source comments.

jar

Creates and manages Java archive files.

03 · JDK

Typical Development Flow

Hello.java
   ↓
javac Hello.java
   ↓
Hello.class
   ↓
java Hello

Key Point

04 · JRE
JRE
04 · JRE

What Is the JRE?

JRE stands for Java Runtime Environment. It provides the environment required to run Java applications.

04 · JRE

In Simple Words

• JRE is mainly associated with running Java applications.
• It includes the JVM and required runtime libraries.
• It does not provide the full set of development tools found in the JDK.
04 · JRE

Think of It This Way

JDK

Build the program.

JRE

Provide the runtime environment.

JVM

Execute the bytecode.

04 · JRE

Key Point

JRE = Environment to RUN Java programs
05 · JVM
JVM
05 · JVM

What Is the JVM?

JVM stands for Java Virtual Machine. It is the runtime engine that executes Java bytecode.

05 · JVM

In Simple Words

• The Java compiler produces bytecode.
• The JVM loads and executes that bytecode.
• Different operating systems can have different JVM implementations.
• This is a major reason Java programs can be portable.
05 · JVM

JVM at a Glance

Class Loader

Loads Java class files into memory.

Bytecode Verifier

Checks bytecode for structural and safety constraints.

Execution Engine

Executes bytecode, including through JIT compilation.

Runtime Areas

Provide memory areas used during execution.

05 · JVM

Java Execution Model

Java Source Code
       ↓
     javac
       ↓
    Bytecode
       ↓
      JVM
       ↓
   Machine Execution

What Is a Variable?

A variable is a named memory location used to store a value that can be used by a Java program.

07 · Variables

In Simple Words

• A variable has a name.
• It has a data type.
• It stores a value.
• Its value can change during program execution, unless declared final.
07 · Variables
General Syntax
dataType variableName = value;
07 · Variables

Syntax Breakdown

• dataType → specifies what kind of value is stored.
• variableName → identifies the variable.
• = → assignment operator.
• value → initial value assigned to the variable.

What Is an Array?

An array is a fixed-size collection of elements of the same data type stored under one variable name.

08 · Arrays

In Simple Words

• Arrays store multiple values of the same type.
• Each element is accessed using an index.
• Java array indexing starts at 0.
• The array length is available through the length property.

What Are StringBuffer & StringBuilder?

StringBuffer and StringBuilder are mutable character sequences used when text needs to be modified repeatedly.

12 · StringBuffer & StringBuilder

Why Not Always String?

String

Immutable — modifications create new String objects.

StringBuffer

Mutable and synchronized; useful when thread safety is required.

StringBuilder

Mutable and generally faster for single-threaded string manipulation.
